# World Tour

세계 여행 개인 포트폴리오를 위한 반응형 웹 기본 틀입니다.
HTML과 CSS만 사용하며, JavaScript 기능이나 외부 의존성은 없습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 빌드는 필요하지 않습니다.

## 폴더 구조

```text
WorldTour/
├── index.html           # 상단, 소개, 여행 기록, 하단
├── css/
│   └── style.css        # 기본 스타일 및 반응형 레이아웃
├── assets/
│   └── images/          # 추후 여행 사진 저장
└── README.md
```

## 반응형 기준

- 모바일: 소개 세로 배치, 여행 기록 1열
- 48rem 이상 (기본 글꼴 기준 768px): 여행 기록 2열
- 64rem 이상 (기본 글꼴 기준 1024px): 소개 2열, 여행 기록 3열
- 콘텐츠 최대 폭: 1200px

## 다음 디자인 작업

- `css/style.css`의 `:root`에서 색상, 콘텐츠 폭, 여백을 조정합니다.
- `index.html`에서 제목과 소개 문구를 수정합니다.
- 사진은 `assets/images/`에 넣고 이미지 자리의 `div`를 `img`로 교체합니다. 사진 내용을 설명하는 `alt`를 함께 작성합니다.
- 여행 항목은 `.travel-card` 구조를 복사해 추가합니다.

현재 이미지와 여행지 문구는 레이아웃 확인을 위한 자리 표시자입니다.
메뉴, 버튼, 지도, 검색 등 동작하는 기능은 아직 추가하지 않았습니다.
