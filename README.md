# World Tour

세계 여행 개인 포트폴리오 웹사이트입니다.
배경 영상, 중앙의 `Feel your freedom` 문구, 작은 플레이바로 구성되어 있습니다.
첫 화면에서 문구가 왼쪽부터 한 글자씩 투명한 상태에서 흰색으로 나타납니다.
문구가 완성되면 60px 위로 이동하면서 채움이 사라지고 흰색 윤곽선만 남아, 글자 안으로 배경 영상이 보입니다.
제공된 꽃밭 영상을 전체 화면 배경으로 사용합니다. 6초 구간마다 0.65초 교차 전환하며 반복 재생합니다.
HTML, CSS, JavaScript로 구성되며 외부 의존성은 없습니다.
영상은 무음으로 재생되고, 화면 상단 중앙의 작은 플레이바에 진행률이 표시됩니다. 아이콘으로 일시정지하거나 이어 재생할 수 있습니다. 동작 줄이기 설정에서는 자동 재생하지 않습니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치나 빌드는 필요하지 않습니다.

## 폴더 구조

```text
WorldTour/
├── index.html           # 배경 영상과 플레이바
├── css/
│   └── style.css        # 기본 스타일
├── assets/
│   ├── images/          # 추후 여행 사진 저장
│   └── videos/          # 배경 MP4 영상
├── js/
│   └── background-video.js # 배경 영상 재생과 전환
└── README.md
```
