국가 페이지 공통 사진 방향 버튼

공통 파일
- pages/countries/common/css/photo-navigation.css: 버튼 배치와 상태별 디자인
- pages/countries/common/js/photo-navigation.js: 카드 너비와 간격에 따른 좌우 이동
- pages/countries/common/assets/navigation/: 전달받은 기본, hover, focus, disabled PNG

국가 페이지 적용 방법
1. 공통 CSS와 JS를 페이지에서 연결합니다. main.js보다 먼저 JS를 불러옵니다.
2. 가로 스크롤 영역 바로 아래에 photo-navigation 요소를 둡니다.
3. 내부에 photo-navigation__button 클래스 버튼 두 개를 넣고
   data-direction을 prev와 next로 지정합니다.
4. 버튼에 type="button", aria-label, 사진 영역 ID를 가리키는 aria-controls를 지정합니다.
5. WorldTour.createPhotoNavigation(사진영역요소, 버튼영역요소)를 호출합니다.

사진 영역의 직계 자식은 사진과 설명을 함께 담은 카드여야 합니다.
사진 영역은 overflow-x: auto, 가로 grid 또는 flex 배치를 사용합니다.
카드 너비와 column-gap은 해당 국가의 레이아웃 CSS에서 관리합니다.
공통 JS에는 국가 이름, 사진 경로, 카드 개수를 고정하지 않습니다.
한 페이지에 여러 사진 영역을 넣을 때는 영역마다 별도로 초기화합니다.

동작
- 한 번 누르면 카드 너비 + 카드 간격만큼 이동합니다.
- 마지막 사진까지 남은 거리가 짧으면 스크롤 끝까지만 이동합니다.
- 처음/끝에서는 해당 방향 버튼을 비활성화합니다.
- 사진이 모두 들어오는 화면에서는 버튼 영역을 숨깁니다.
- 터치 스크롤, 화면 크기 변경에도 버튼 상태가 갱신됩니다.
- 모션 감소 설정에서는 애니메이션 없이 이동합니다.
- 기본 이동 시간은 650ms이며 부드러운 가속/감속을 적용합니다.
- 세 번째 인자로 { duration: 800 } 등을 전달하면 국가별로 속도를 조절할 수 있습니다.
- 연속 클릭은 목표 위치에 누적되며, 터치/휠/키보드 직접 조작은 진행 중인 애니메이션을 중단합니다.
- 반환된 객체의 refresh()로 상태 갱신, destroy()로 이벤트와 관찰을 해제합니다.
