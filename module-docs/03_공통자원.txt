공통 자원 및 디자인 자료

[공통 스타일]
shared/css/tokens.css
- --color-page: 기본 페이지 배경
- --color-text: 기본 글자색
- --color-map-background: 지도 및 지도 미리보기 배경
- --color-landing-background: 첫 화면과 로딩 화면 배경

shared/css/base.css
- box-sizing, 기본 여백, 글꼴, 줄 간격, 이미지 기본값을 설정합니다.
- 두 HTML에서 공통으로 불러옵니다.
- 공통 변경은 두 페이지에 영향을 주므로 양쪽을 함께 확인합니다.

[공통 이미지]
shared/images/world-map-dark-en.png
- 실제 서비스 화면에서 사용하는 영문 다크 네이비 지도입니다.
- index.html의 전환 미리보기와 selectWorldMap.html이 함께 참조합니다.
- 지도 데이터 생성 스크립트의 입력이기도 합니다.
- 실제 이미지 해상도는 1672 × 941px입니다.

[디자인 기록]
design/concepts/
- 초기 지도 시안과 관련 프롬프트를 보관합니다.

design/generated/
- 생성한 밝은 지도, 다크 지도, 영문 지도 원본을 보관합니다.
- 생성·편집 프롬프트와 대륙 영역 검증 이미지를 보관합니다.
- 실행 페이지는 이 폴더의 파일을 직접 사용하지 않습니다.

[관리 원칙]
공통 자원은 shared/에 두고 페이지 전용 자원은 각 pages/ 하위에 둡니다.
실행용 이미지 수정과 디자인 원본 보관을 구분합니다.
HTML의 상대 경로는 HTML이 위치한 프로젝트 루트를 기준으로 작성합니다.
