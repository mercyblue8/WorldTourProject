세계지도 모듈 — WORLD MAP

진입 파일: selectWorldMap.html
전용 폴더: pages/world-map/

[HTML]
selectWorldMap.html
- 지도 이미지와 대륙 감지 영역을 담는 SVG를 배치합니다.
- 긴 윤곽 좌표는 데이터 파일로 분리되어 있습니다.
- 지도 이미지: shared/images/world-map-dark-en.png

[CSS]
css/page.css
- 화면 중앙 배치, 지도 비율과 크기를 담당합니다.
- 1672:941 비율을 유지하며 지도 전체를 표시합니다.
- 화면 비율에 따라 여백이 생길 수 있습니다.
- 이미지 위 SVG 감지 영역을 같은 위치와 크기로 맞춥니다.

css/continent.css
- 마우스 Hover와 키보드 Focus 시 대륙 강조 효과를 담당합니다.
- 밝은 채움, 테두리, Glow와 전환 시간을 설정합니다.
- 포인터가 벗어나면 기본 상태로 돌아갑니다.

[데이터]
data/continents.js
- window.WorldTour.continents에 지도 데이터가 저장됩니다.
- width, height: 기준 지도 크기
- regions: 대륙 목록
- 각 항목: id, label, path

대륙 목록
north-america — North America
south-america — South America
europe        — Europe
africa        — Africa
asia          — Asia
oceania       — Oceania
antarctica    — Antarctica

[JavaScript]
js/main.js
- initWorldMap(root)로 SVG 대륙 영역을 생성합니다.
- 각 영역에 대륙 ID, 이름, 윤곽, 키보드 포커스 속성을 설정합니다.
- 다시 초기화해도 영역이 중복되지 않도록 기존 자식을 교체합니다.
- 강조 효과 자체는 JS가 아닌 CSS에서 처리합니다.

[로드 순서]
공통 tokens.css → base.css → page.css → continent.css
continents.js → main.js

[수정 시 확인]
지도 이미지를 교체하면 기존 윤곽과 새 이미지의 위치가 맞는지 확인합니다.
이미지 크기나 비율을 바꾸면 HTML 크기 속성과 page.css도 함께 수정합니다.
생성된 path를 직접 고치기보다 scripts/build-map-regions.py로 재생성합니다.
현재 아시아는 클릭 또는 Enter/Space로 아시아 페이지에 진입할 수 있습니다.
다른 대륙은 Hover/Focus 강조만 지원합니다.
추가된 navigation.js와 navigation.css의 설명은 06_아시아진입모듈.txt를 참고하세요.
