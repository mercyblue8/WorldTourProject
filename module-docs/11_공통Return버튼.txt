국가 페이지 공통 Return 버튼

파일
- pages/countries/common/css/country-return.css: 고정 버튼, 흐림 및 지도 페이드 효과
- pages/countries/common/js/country-return.js: 복귀 동작과 전환 미리보기 생성

사용 방법
1. 해당 국가 HTML에 공통 CSS와 JS를 연결합니다. JS는 main.js 앞에 둡니다.
2. <a class="country-back" href="상위 지도 주소">Return</a>를 둡니다.
3. 국가 config에 parentHref(복귀 주소), parentMapImage(지도 이미지 주소)를 지정합니다.
   두 경로 모두 해당 HTML 기준 상대 경로입니다.
4. main.js에서 WorldTour.createCountryReturn(config)를 호출합니다.

동작
- 이미지 준비 후 900ms 동안 현재 화면을 흐리게 하며 지도를 표시합니다.
- 확대/축소는 사용하지 않습니다.
- 지도는 네이비 배경에 object-fit: contain으로 표시합니다.
- 전환 종료 후 실제 상위 지도 페이지로 한 번 이동합니다.
- Escape로 취소할 수 있고, 수정키 클릭은 일반 링크처럼 작동합니다.
- 모션 감소 설정에서는 180ms 페이드만 사용합니다.
- 실제 이동 시 지도 미리보기를 유지하여 다시 현재 화면이 보이지 않도록 합니다.
- 뒤로가기로 복원되면 버튼과 화면 상태를 초기화합니다.
- 반환된 객체의 destroy()로 이벤트와 생성된 미리보기를 정리할 수 있습니다.

일본은 config의 parentHref와 parentMapImage에 아시아 페이지 및 지도 이미지를 지정합니다.
다른 국가도 동일한 모듈에 각 국가의 상위 지도 정보만 전달하면 됩니다.

국가 진입 전환 미리보기
- 대륙 페이지에서도 country-return.css를 연결합니다.
- country-portal 내부에 <span class="country-back">Return</span>을 배치합니다.
- 미리보기와 실제 국가 페이지가 같은 스타일을 사용하므로 위치와 모양이 일치합니다.
- Return 표시가 배경 이미지와 함께 페이드 인되어, 실제 페이지 진입 후 뒤늦게 나타나는 느낌을 줄입니다.
- country-portal에는 aria-hidden="true"와 inert를 지정합니다. 미리보기는 링크가 아닌 span이므로 클릭과 키보드 탐색 대상이 아닙니다.
- 실제 복귀 동작은 도착한 국가 페이지의 링크가 담당합니다.
