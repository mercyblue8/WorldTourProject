아시아 국가 선택 모듈

기능
국가에 마우스를 올리거나 Tab으로 포커스하면 밝게 빛납니다.
클릭 또는 Enter/Space로 선택 상태를 유지합니다.
다른 국가를 선택하면 이전 선택은 해제됩니다.
같은 국가 재클릭, 바다 클릭 또는 Escape로 선택을 해제합니다.
우측 하단에 한글·영문 국가명과 선택 여부를 표시합니다.
작은 국가는 포인트로 선택할 수 있습니다.
사진 패널은 아직 구현하지 않았습니다.

파일
pages/continents/asia/data/countries.js
  50개 국가·지역 선택 항목. id, name, label과 path 또는 marker 좌표.
  자동 생성 파일이므로 윤곽 변경은 생성 스크립트에서 수행합니다.
pages/continents/common/js/selection.js
  createCountrySelection(data, root)로 생성합니다.
  selectedCountry로 현재 선택을 읽고 destroy()로 정리합니다.
  국가 SVG와 포인트를 생성하고 마우스·키보드 선택을 처리합니다.
pages/continents/common/css/country.css
  Hover·Focus·선택 Glow와 국가명 표시를 담당합니다.
pages/continents/asia/css/page.css
  지도 이미지와 감지 SVG가 같은 비율로 표시되도록 프레임을 관리합니다.
scripts/build-asia-regions.py
  지도 경계 추출과 소형 국가 윤곽 보정을 수행합니다.
  원본 지도 이미지는 수정하지 않습니다.
  Pillow, NumPy가 필요하고 기존 build-map-regions.py의 윤곽 함수를 재사용합니다.
tests/world-map/countries.test.cjs
  대표 좌표, 국가/바다 구분, 선택 상태, 키보드, 해제 및 정리를 검사합니다.

유지보수
국가 시각 효과: country.css
선택 동작: selection.js
국가명·윤곽·포인트: build-asia-regions.py를 수정한 뒤 재생성
명령: python scripts/build-asia-regions.py
지도 교체 시 기존 좌표와 윤곽의 정합성을 다시 확인해야 합니다.
윤곽은 현재 생성 지도에 맞춘 UI 영역으로 공식 지리 데이터가 아닙니다.
작은 국가와 도서 지역은 단순화된 윤곽 또는 포인트를 사용합니다.
