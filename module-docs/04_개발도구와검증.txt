개발 도구와 검증

[지도 영역 생성 도구]
파일: scripts/build-map-regions.py

입력: shared/images/world-map-dark-en.png
출력: pages/world-map/data/continents.js

역할
- 지도 색상과 위치를 기준으로 7개 대륙 영역을 구분합니다.
- 잡음을 제거하고 글자·음영으로 생긴 내부 구멍을 보정합니다.
- 윤곽을 SVG path 데이터로 변환합니다.
- 원본 지도 이미지와 HTML은 수정하지 않습니다.

실행 위치: 프로젝트 루트
명령: python scripts/build-map-regions.py
필요 도구: Python, Pillow, NumPy
브라우저에서 사이트를 실행할 때는 Python이 필요하지 않습니다.

주의
추출 규칙은 현재 지도 색상과 좌표에 맞춰져 있습니다.
새로운 디자인으로 바꾸면 규칙을 수정하고 윤곽 정합성을 확인해야 합니다.

[자동 테스트]
tests/assets.test.cjs
- 두 HTML이 참조하는 파일의 존재와 스크립트 로드 순서를 확인합니다.

tests/landing/transition.test.cjs
- 영상 종료 후 이동, 페이드 완료 대기, 취소, 재생 실패를 검사합니다.
- 동작 줄이기와 모듈 정리 후 재초기화를 검사합니다.

tests/landing/lifecycle.test.cjs
- 로딩 중 배경 영상 정지와 취소 후 재생을 검사합니다.
- 탭 상태, 페이지 복귀, 이벤트 정리, 배경 교차 재생을 검사합니다.

tests/world-map/regions.test.cjs
- 대륙 대표 좌표와 바다의 영역 판정을 검사합니다.
- 접근 가능한 SVG 영역 생성과 중복 방지를 검사합니다.

실행 명령
node --test tests/assets.test.cjs tests/landing/transition.test.cjs tests/landing/lifecycle.test.cjs tests/world-map/regions.test.cjs

검증 기록
모듈화 완료 시 자동 테스트 11개 통과.
이동 전후 실행용 영상·지도 이미지의 원본 일치 확인.
지도 데이터 재생성 결과가 기존 7개 대륙 데이터와 일치함을 확인.
실제 브라우저 시각 검증은 수행하지 못했으며 자동 테스트가 이를 대신하지 않습니다.
