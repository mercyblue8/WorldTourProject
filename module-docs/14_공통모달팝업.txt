국가 페이지 공통 모달 팝업

파일
- pages/countries/common/css/modal.css: 모달 창, 배경 블러, 반응형 크기
- pages/countries/common/js/modal.js: 열기·닫기, 배경 스크롤 잠금과 복구
- pages/countries/common/js/modal-content.js: 카드 데이터로 사진·제목·목록·출처 링크 생성
- pages/asia-countries/japan/data/modal-cards.js: 일본 카드별 콘텐츠 (config.js 다음에 로드)

사용 방법
1. 국가 HTML에 공통 CSS와 JS를 연결합니다. JS는 해당 국가 main.js 앞에 둡니다.
2. button에 data-country-modal="모달ID", aria-haspopup="dialog", aria-controls="모달ID"를 지정합니다.
3. dialog에 같은 ID와 country-modal 클래스를 지정하고 aria-labelledby로 제목을 연결합니다.
4. country-modal__header에 닫기 버튼을 두고 country-modal__content에 본문을 구성합니다.
   본문의 country-modal__layout 안에 country-modal__visual(사진)과 country-modal__details(설명)를 둡니다.
   country-modal__details에 country-modal__title과 필요한 소개 문단을 배치합니다.
5. 닫기 button에 data-modal-close, country-modal__close, aria-label="모달 닫기"를 지정합니다.
   country-modal__close-group 안에 country-modal__shortcut 클래스의 kbd(ESC)와 닫기 버튼을 배치합니다.
   ESC 안내는 10px로 표시하며 버튼에 aria-keyshortcuts="Escape"를 지정합니다.
6. main.js에서 WorldTour.createCountryModal(document.querySelector('#모달ID'))를 호출합니다.
   데이터 기반 모달은 세 번째 인자에 { beforeOpen: trigger => ... }를 전달합니다.
   콜백에서 data-modal-card의 ID로 데이터를 찾아 renderCountryModalContent(dialog, card)를 호출합니다.
   없는 ID나 필수 데이터 누락 시 false를 반환하면 빈 모달을 열지 않습니다.
   모든 카드 버튼의 data-country-modal과 aria-controls는 재사용할 모달 하나의 ID를 가리킵니다.

동작
- 네이티브 dialog.showModal()로 배경 조작을 차단하고 키보드 포커스를 모달 안에 유지합니다.
- 배경에 반투명 어두운 색과 12px 블러를 적용합니다.
- 닫기 버튼, Esc, 창 밖 배경 클릭으로 닫습니다. 내부에서 시작한 드래그는 배경 닫기로 처리하지 않습니다.
- 열었을 때 배경 스크롤을 잠그고, 닫을 때 기존 위치와 실행 버튼의 포커스를 복원합니다.
- 원래 세로 스크롤이 있던 페이지는 모달 표시 중에도 스크롤바 트랙과 공간을 유지하여 가로 배치가 바뀌지 않게 합니다. 배경 스크롤은 잠기며, 짧은 페이지에는 스크롤바를 추가하지 않습니다.
- 긴 콘텐츠는 모달 내부에서 스크롤하며 닫기 버튼은 상단에 유지됩니다.
- 동작 줄이기 설정에서는 등장 애니메이션을 생략합니다.
- 닫을 때 모달의 불투명도와 배경의 어두움·블러를 300ms 동안 함께 줄입니다.
- 종료 후 실제 dialog를 닫고 스크롤과 포커스를 복원합니다. 반복 닫기 요청은 무시합니다.
- 닫힘 시간은 공통 CSS의 --modal-exit-ms에서 조절합니다. 종료 이벤트 누락 시 보조 타이머로 복원합니다.
- 동작 줄이기 설정, 페이지 이탈, destroy()에서는 즉시 닫고 대기 중인 애니메이션 상태를 정리합니다.
- 반환 객체의 close()로 닫고 destroy()로 이벤트를 정리할 수 있습니다.

현재 연결
- 디즈니랜드만 layout: 'gallery'를 지정하여 지역 문구·제목·가로 사진 슬라이더·설명 순서로 표시합니다.
- images 배열의 src/alt를 수정하면 사진을 교체·추가할 수 있습니다. 현재 동일 사진 세 장은 배치 테스트용입니다.
- 갤러리는 기존 createPhotoNavigation과 방향 버튼 스타일을 재사용합니다. modal-content.js보다 먼저 photo-navigation.js를 연결합니다.
- 다른 카드로 전환할 때 갤러리 이벤트와 관찰자를 정리하고 일반 좌우 레이아웃을 복원합니다.
- 일본 페이지의 시부야 스크램블, 신주쿠 클럽 워프, 도쿄 디즈니랜드 이미지 버튼을 연결했습니다.
- 디즈니랜드에도 사용자 지정에 따라 동일한 도쿄 context 문구를 표시합니다.
- 데스크톱에서는 사진 왼쪽·설명 오른쪽, 700px 이하에서는 사진 위·설명 아래로 표시합니다.
- 닫기 영역은 고정하고 본문만 스크롤하여 작은 화면에서도 닫기 버튼에 접근할 수 있습니다.
- 배치와 타이포그래피는 공통 CSS에서, 사진과 소개 문구는 일본 data/modal-cards.js에서 관리합니다.
- 카드마다 context, eyebrow, title, subtitle, image, sections를 지정합니다. image.src는 일본 HTML 기준 경로입니다.
- sections는 title, type(bullet-list 또는 numbered-list), items로 구성합니다.
- 항목은 text, 선택적 label(굵은 제목), 선택적 sources([{ label, href }])를 가집니다.
- 일반 문자열을 DOM 텍스트로 표시하며 HTML 문자열은 해석하지 않습니다.
- 카드를 바꿀 때 이전 설명을 교체하고 본문 스크롤을 맨 위로 초기화합니다. context가 없으면 상단 지역 문구를 숨깁니다.
- 신주쿠 클럽 워프의 설명은 modal-cards.js의 shinjuku-warp 항목에서 수정합니다.
- 선택적 lead는 부제 아래의 소개 문단입니다. subtitle의 줄바꿈(\n)은 화면에도 반영됩니다.
- 모달은 shared/css/typography.css의 --font-sans(Noto Sans KR)를 사용합니다.
- 선택적인 country-modal__context를 헤더에 넣으면 좌측 상단에 지역 문구를 표시합니다.
- 'Tokyo | 東京 - 밤이 더 환하게 빛나는 도시'는 일본의 도쿄 카드 모달에만 넣는 콘텐츠이며 공통 기본 문구가 아닙니다.
- 카드의 이미지 버튼 스타일은 공통 photo-card.css의 country-photo-card__trigger를 사용합니다.
