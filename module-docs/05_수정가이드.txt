함께 맞춰야 하는 설정
1. 배경 교차 재생
   JS fadeLength: 0.65초
   CSS opacity 전환: 650ms
2. 지도 전환
   CSS 확대·페이드: 1100ms
   JS 보조 이동 타이머: 1400ms
   정상 이동 기준: opacity transitionend
3. 지도 크기
   HTML 이미지 width/height, 지도 CSS 비율, 데이터 width/height,
   지도 미리보기와 실제 지도 이미지가 일치해야 합니다.

변경 후 확인 순서
1. 자동 테스트 실행
2. index.html 직접 열기
3. GO → 영상 종료 → 지도 이동 확인
4. Escape 및 처음으로 버튼 확인
5. 브라우저 뒤로 가기 후 GO 재실행
6. 대륙 Hover와 Tab 포커스 확인
7. 화면 크기를 바꿔 지도와 감지 영역 정렬 확인
8. 동작 줄이기 설정 확인
